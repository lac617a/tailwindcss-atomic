# Conservar y runtime

## Qué se deja intacto

El motor Rust (WASM) solo atomiciza reglas de **utilidad**. Se conservan:

- `@theme`
- `:root`
- preflight
- `@keyframes`
- at-rules anidadas (`@media`, `@supports`, `@container`)

El resto del selector se **conserva**: `._hash:hover`, combinadores de `space-y-*`, el `@media` de `sm:`. No se pierde hover ni breakpoints.

Las clases custom que no tienen forma de utilidad (`.header-signin`) se dejan. Las que *sí* parecen utilidades (`text-logo`, `flex-container`) necesitan `preserveClasses`.

## `twIgnore`

Envuelve strings que no deban tocarse:

```tsx
import {twIgnore} from "tailwindcss-atomic/runtime";

<div className={twIgnore("flex hidden")} />
```

Añade más nombres con `preserveFunctions` si tu código usa otro helper.

## Runtime `cn` / Tailwind Merge

Si usas `tailwind-merge` en runtime, las clases hasheadas ya no parecen utilidades de Tailwind. El bundler envuelve `cn` / `clsx` / `cx` / `twMerge` con `_twAtomicReconcile`: **deshashea**, corre `twMerge` y vuelve a hashear. El merge sigue viendo los tokens originales.

<Callout type="info">
  La mayoría de apps no necesita importar `runtime` a mano: el rewrite ocurre en el build. Usa `twIgnore` cuando el string deba quedarse literal.
</Callout>

### `bg-opacity-*` se come el color (tailwind-merge v3)

Con **tailwind-merge v3** (Tailwind CSS v4), `bg-opacity-50` se trata como otro `bg-*`. Gana **la última** clase y desaparece el color:

```ts
twMerge("bg-neutral-300 bg-opacity-50");
// → "bg-opacity-50"
```

En el DOM queda el hash de `bg-opacity-50` (`--tw-bg-opacity: .5`) y **no hay `background-color`**. Lo mismo con `text-opacity-*` y `border-opacity-*`.

No es un fallo del hasher. Sale en componentes con `cx()` / `cn()` (esas llamadas se reconcilian). Un `cva()` no se envuelve, así que al lado un skeleton puede “perder” el relleno y el resto de la UI verse bien.

Usa el modificador con `/` en lugar de las dos clases:

```tsx
// ❌ tailwind-merge v3 tira bg-neutral-300
cx("rounded-lg bg-neutral-300 bg-opacity-50", className);

// ✅ una sola utilidad: color + opacidad
cx("rounded-lg bg-neutral-300/50", className);
```

El mismo patrón: `text-black/50`, `border-neutral-300/50`. Ver [tailwind-merge#579](https://github.com/dcastil/tailwind-merge/issues/579).
